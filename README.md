# AIAIAI Store



Progetto di fine anno scolastico 2025/2026.



In questo progetto ho implementato per la prima volta una logica server-side,

in questo caso utilizzando PHP, segnando un passo avanti rispetto ai progetti

precedenti basati solo su HTML, CSS e JavaScript.



## Contenuto del repository

- File PHP per tutta la logica applicativa

- Fogli di stile CSS

- File SQL per la creazione e il popolamento del database

- Relazione tecnica del progetto



## Descrizione

Piattaforma e-commerce per la vendita di abbonamenti mensili ad agenti di 

Intelligenza Artificiale, sviluppata con PHP procedurale e database MySQL.
